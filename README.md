## 住宅 IP、原生 IP、机房 IP，三个词不能混着用

测试脚本的判定里，这三样是分开的。原生 IP 指 IP 的归属地和机房实际所在地一致，注册信息没被挂到别的国家；住宅 IP 指这段地址属于运营商分配给家庭宽带的池子；机房 IP 就是 IDC 段。一台机器可以同时是“原生”和“机房”。

有现成的例子。某次数码测评里，V.PS 香港那台机器被所有脚本判定为香港原生 IP、纯净度高，风险评分也低，但同时被判定为 IDC 机房 IP。也就是说，它“干净”，却不“像家宽”。这份测评另一个数字更能说明问题：到内地平均延迟 335ms，电信去程绕德国法国再经新加坡到香港，回程绕日本美国，联通回程还多绕一趟德国。原生 IP 和线路优化完全是两条独立的线，一条达标不代表另一条也达标。

WePC 卖的正是另一头的东西。2026 年 3 月一份第三方测评对西班牙那档的判断是“真正的西班牙原生 IP，带住宅属性”，能解锁当地 TikTok、ChatGPT、Claude、Netflix、Disney+，Gemini 不行。同一份测评也写了反面：国内直连延迟高，晚高峰不中转几乎没速度，机器本身性能偏弱，I/O 约 194.7MB/s。

这两段要一起看。给当地人用的业务，比如西班牙市场的店铺、当地 TikTok 直播、需要当地身份验证的注册，住宅 IP 是硬门槛，机房 IP 再快也过不了。给自己用的业务，比如远程开发、建站、中转，那 335ms 和晚高峰掉速才是要命的，IP 是不是住宅无所谓。

## 测评到底测哪四项

一套完整的测试覆盖四块：CPU（sysbench 单核或 Geekbench）、内存读写（反映 DDR 世代）、磁盘 4K 随机读写 IOPS（模拟真实业务负载）、网络（带宽实测、国内三网延迟、回程路由走向）。IP 质量检测和流媒体解锁算进阶项，做跨境和流媒体的必须加。

网上流传的一套“2026 年及格线”可以当坐标用，但要说清楚：它出自一篇带推广链接的测评文，是作者自拟口径，不是行业标准。不同业务对同一指标的敏感度差很远，别把它当判决书。

| 指标 | 参考线 |
| --- | --- |
| CPU（sysbench 单核） | <600 不合格；600–800 合格；>800 优秀 |
| 内存读写 | >5,000 MB/s 合格；>10,000 MB/s 优秀 |
| 磁盘 4K 随机读 | <5,000 IOPS 不合格；5,000–15,000 合格；>15,000 优秀；>30,000 顶级 |
| 网络下载 | <100 Mbps 不合格；100 Mbps–1 Gbps 合格；>1 Gbps 优秀 |
| 国内三网延迟均值 | <100ms 优秀；100–200ms 良好；>200ms 较差 |

我自己的判断口径跟这套略有出入：建站和接口服务，4K 随机读低于 10,000 IOPS 就别考虑了，晚高峰丢包超过 1% 也要打折；做中转和远程桌面，回程是否三网直连比跑分重要得多；做短视频和直播，IP 性质排第一，带宽第二，CPU 最后。同一条及格线，套在不同场景上结论会翻。

## 结果怎么读：三组数字决定去留

第一组看硬件真假。开机先 `cat /proc/cpuinfo | grep "model name" | uniq`，核对 CPU 型号和你买的那档对不对，再 `free -h` 和 `df -h` 看内存硬盘有没有缩水。型号对不上，后面都不用测了。

第二组看磁盘。顺序读写好看不代表什么，4K 随机读才是真实业务下的水位。低于 5,000 IOPS 基本可以判定超售或者上了便宜盘，这种机器白天能用晚上崩，退款比折腾划算。NVMe 和 SATA SSD 在这个指标上差距明显，下单前问清给的是哪种。

第三组看网络，重点是回程。去程优化是标配，回程走 163 还是 9929 才是分水岭。测速要加国内三网节点，只跑国际节点没有参考价值。另外标称 500Mbps 不等于你能跑满，看单线程和多线程的实测，尤其是晚高峰八点到十一点的实测。

有人给过一个性价比速算：4K 随机读 IOPS ÷ 月费。用的时候注意币种，公式的分母是人民币月费，拿澳元或欧元的套餐直接套会把分数算高一大截，先换算再除。WePC 全部澳元标价，西班牙那档在测评里写的是 $19.9 且没标币种，比价前先确认结算页显示的是什么货币。

还有一条容易被当成翻车的：带宽默认是共享的。DigitalVirt 在条款里写明带宽默认共享，官方承诺 99% 时段达到标称值。这意味着晚高峰跑不满标称速度，不一定是超售，先确认自己买的是不是共享款，再看有没有别的指标同时变差。

## 五个常见的测试陷阱

**只测去程不看回程。** 去程优化是标配，回程才见真章，融合怪的三网回程路由一定拉到最下面看。

**测速只跑 Speedtest 国际节点。** 国际节点跑得快和国内访问快是两回事，要加测北京、上海、广州的移动联通电信节点。

**磁盘只看顺序读写。** 顺序读写好看但 4K 随机差，说明盘便宜或者超售严重。

**测一次就下结论。** 邻居负载会波动，早高峰、晚高峰、凌晨各测一次，看的是稳定性不是峰值。

**忽视超售检测。** 没有主动负载时 CPU、内存、IO 长期高占用，基本就是超售，挂机观察几小时就能看出来。

再补两条。测评数据是快照，不是承诺，线路会调整、IP 段会更换，三个月前的数据参考价值要打折，看到 2026 年 3 月的测试结果就要想到配置和价格可能已经变了。还有别把“原生 IP”和“优化线路”当成同一件事，V.PS 香港那台就是活例子，IP 干净得很，电信联通照样绕半个地球。
